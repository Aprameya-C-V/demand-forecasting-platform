03

What makes it production

01
Promotion is a gate

Every retrain is registered, but only a challenger that beats the champion by 2% WAPE takes the production alias. The alias decides what serves, not the code.

02
Monitoring has teeth

A breach fails the workflow and opens a GitHub issue with the metric, the window and the runbook section. Regressions become tickets, not dashboards.

03
Contracts before models

The panel is validated for density, nulls, duplicates and zone count before training. A silently missing slot would corrupt every lag above it.

04
Observability by default

Request ID, model version and latency on every response and in every log line. Prometheus counters, a latency histogram and a batch size histogram.

05
Rollback is one line

Aliases are data. Point production at a previous version, redeploy, confirm with the version header. No rebuild, no migration.

06
One feature path

Training and serving reshape the same dense panel into the same cube, so a served lag cannot drift from a trained one.
